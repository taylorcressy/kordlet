# Contributing

Read [AGENTS.md](AGENTS.md), [the development workflow](docs/development/workflow.md), and [the setup guide](docs/development/setup.md). For a new operation, define its schema and role in the contract registry, implement the service handler, add success/error and relevant concurrency fixtures, regenerate artifacts, and run local verification. Describe any wire compatibility and data migration impact. Submit small changes with local check evidence once the project has a remote and an approved delivery path.

A future CODEOWNERS file must use maintainer-provided identities.
