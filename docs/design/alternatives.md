# Kordlet design alternatives

The default Boardroom is based on [sample_ux.png](sample_ux.png). Its graphite lanes let a maintainer scan work by status with the issue inspector open.

- Dispatch emphasizes the priority queue and claim ownership for teams coordinating multiple agents.
- Review desk emphasizes acceptance criteria, evidence, and the exact revision under review.
- Dependency map prioritizes prerequisite relationships through a keyboard-accessible tree and bounded visual view.
- Briefcase centers an epic's description and acceptance criteria, with linked work and decisions nearby.
